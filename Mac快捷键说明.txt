Mac 常用快捷键模式（Windows 客户端，2026-10-23）

在主界面选择“配置客户端”，勾选“远程操作时使用 Mac 快捷键”并保存。
默认关闭。保存后自动重新连接，开关在新连接中生效。

开启后仅转换 ⌘C/V/X/Z/A/F/S 为 Ctrl+C/V/X/Z/A/F/S，支持 Shift 组合。
⌘Tab、⌘Q、⌘方向键及其他组合保留关闭开关时的原有映射。
带 Option 或 Control 的组合也保持原映射；Windows 本机实体键盘不受影响。
这是常用组合键的转换，不是完整的 macOS 快捷键模拟。
Command 单独点击和配合鼠标的操作保留原映射。
Command 按下先等待组合键；命中常用列表时只对该组合使用 Ctrl，
未命中时送出原有 Command。松开、重复和跨屏离开均处理对应状态。

只需更新 Windows 客户端，现有 Mac 服务端无需重新构建。
沿用此前的 LittleBigMouse 支持、跨电脑边缘切换、文件中继、速度设置、语言切换与高负载优化。

验证：14 组回归测试通过；常用字母、重复、松键、左右 Command、其他组合、
同一次 Command 按住时切换组合、鼠标修饰键及跨屏状态清理等用例通过。
原生 KeyMap 测试确认 Ctrl 按下、C 按下、Ctrl 松开的顺序和修饰状态恢复。
不读取每次按键的磁盘配置；关闭开关时直接走原有修饰键翻译。
Mac 到 Windows 的实际应用快捷键效果仍需现场验证。
